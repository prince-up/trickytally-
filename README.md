# trickyTally

trickyTally is a MERN stack web application designed to record and manage Call Break game scores digitally.

## Features
- User authentication (Login / Signup)
- Create Call Break game sessions
- Add players and round-wise bids & tricks
- Automatic score calculation
- Game history stored in MongoDB

## Tech Stack
- Frontend: React + TypeScript
- Backend: Node.js + Express
- Database: MongoDB
- Authentication: JWT

## Purpose
This project was built to replace manual score tracking with a simple and reliable digital solution.
